เป็นเวปสาธารณะที่เปิดให้บริการให้สำหรับผู้ที่ต้องการวางแผนการเดินทาง เช่นคำนวนค่าใช้จ่ายในการเดินทาง ค่าเชื่อเพลิง และยังสามารถเปรียบเทียบกับบริการที่คล้ายกันบนแพรตฟอร์มอื่นๆที่ให้บริการในรูปแบบเดียวกัน อีกทั้งคุณยังสามารถกำหนดเส้นทางในการเดินทางด้วยพาหนะส่วนบุคคลหรือสาธารณะ หากผู้ที่ต้องการประหยัดหรือควบคุมค่าใช้จ่าย เวปนี้ตอบโจทย์คุณเป็นอย่างดี
